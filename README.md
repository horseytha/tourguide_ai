# tourguide_ai

Wanderly is a browser-based trip planner for European city breaks. It includes a day-by-day itinerary, sample hotel recommendations, a route map, trip budget and expense tracking, a packing checklist, trip notes, CSV export, and a planning assistant.

## Run locally

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
